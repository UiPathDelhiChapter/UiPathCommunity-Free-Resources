# 🤖 UiPath Community - Free Resources

### Learn. Build. Share. Grow together.

Welcome to **UiPath Community - Free Resources**, a community-driven initiative by the **UiPath Delhi Chapter** to make automation learning more accessible, practical, and collaborative.

Our goal is to bring together useful learning materials, sample projects, templates, and hands-on guides for the global UiPath community, from students and beginners to experienced developers and solution architects.

> 🚧 **Repository status:** Initial setup. The areas below describe the planned scope; resources will appear as contributions are added.

## 🎯 What This Repository Is For

This repository is a place to share practical knowledge, learn through examples, and help others explore RPA, AI, and agentic automation. Contributions should explain not only **what a solution does**, but also **how to set it up, run it, and understand the results**.

## 📚 Planned Resource Areas

| Area | Examples of welcome contributions |

These are contribution categories, not a guarantee that a particular resource is already available.

## 🚀 Getting Started

Once resources have been added:

1. **Choose a resource** that matches your topic and experience level.
2. **Read its README** for prerequisites, supported versions, dependencies, and setup instructions.
3. **Download or clone the repository**, then follow the resource-specific instructions.
4. **Run the example in a development or test environment** and compare your results with the documented output.

To clone the repository:

```bash
git clone https://github.com/UiPathDelhiChapter/UiPathCommunity-Free-Resources.git
cd UiPathCommunity-Free-Resources
```

There is no single installation or run command for the entire repository. Each project must document its own requirements.

> 💡 **Free resources, not bundled licenses:** This repository does not provide software licenses, cloud credits, or third-party subscriptions. Contributors must identify any access requirements or potential usage costs.

## 🤝 Contributing

Everyone is welcome to contribute. You can share a sample project, improve an explanation, fix an issue, or suggest a useful learning resource.

1. Open an issue to discuss a substantial new contribution or propose a topic.
2. Fork the repository and create a branch for your changes.
3. Add your resource in a clearly named topic folder, with its own README and supporting files.
4. Submit a pull request describing what you added, who it helps, and how you tested it.

Use descriptive folder names such as `RPA/Excel-Data-Processing` or `Agentic-Automation/Invoice-Review-Agent`. These are examples, not existing folders.

### 📋 What Every Resource Should Include

| Item | Required details |
| --- | --- |
| **Overview** | The problem, learning objective, intended audience, and difficulty level. |
| **Prerequisites** | Required tools, tested versions, package dependencies, permissions, and license or service requirements. |
| **Setup and execution** | Step-by-step instructions, configuration placeholders, and safe sample inputs. |
| **Expected results** | Sample output, verification steps, and screenshots where useful. |
| **Limitations** | Known issues, assumptions, troubleshooting notes, and the last tested date. |
| **Attribution and licensing** | Contributor details, original sources, and applicable license information. |

### ✅ Contribution Standards

- **Keep it safe:** Never upload credentials, API keys, access tokens, customer information, or confidential documents. Use synthetic data and placeholder configuration values.
- **Keep it usable:** Test runnable examples, document dependencies, and distinguish working samples from conceptual demonstrations. Exclude unnecessary generated files and logs.
- **Respect ownership:** Share only material you have permission to publish, credit original authors, and link to external resources rather than copying restricted content.
- **Keep it welcoming:** Use clear explanations, give constructive feedback, and treat contributors of every experience level with respect.

## 💬 Questions, Issues, and Resource Requests

Use [GitHub Issues](https://github.com/UiPathDelhiChapter/UiPathCommunity-Free-Resources/issues) to report a problem, suggest an improvement, or request a learning topic.

For a technical issue, include the resource name, tool and package versions, steps to reproduce, expected behavior, and actual behavior. Remove sensitive information from logs and screenshots before sharing them.
